# 🎮 Bleacher

A Roblox battlegrounds-style fighting game.

## About the Project

I enjoy making and experimenting with video games in my free time, particularly through Roblox Studio. **Bleacher** is a personal game development project centered around multiplayer combat, where players can fight each other using different abilities and special powers.

The game takes inspiration from Jujutsu Shenanigans, using its battlegrounds-style gameplay as a reference for combat, player interactions, and overall design.

## Development & Technologies

- **Roblox Studio** – Game development environment.
- **Luau** – Scripting combat mechanics, abilities, and gameplay systems.
- **Roblox Engine** – 3D environments, physics, and multiplayer functionality.

## Purpose & Takeaways

Game development has been a long-standing personal interest of mine. Working on Bleacher has given me an opportunity to experiment with combat systems, scripting, multiplayer mechanics, and game design.

I enjoy building games from the ground up, testing new ideas, solving problems, and continuously improving the experience.
